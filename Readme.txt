🎮 About

Emojis Hunt is a fast-paced command-line memory game written in Python.

The game presents two randomly shuffled arrays of emojis for a limited amount of time. The player must memorize the exact positions of the target emoji in both arrays.

After the arrays disappear, the player must enter the correct positions from memory.

«🧠 One wrong answer ends the game!»

Each successful round becomes progressively harder as the display time decreases.

---

🎯 Objective

The objective of Emojis Hunt is to build a fun and interactive memory-training game using core Python concepts.

---

✨ Features

- 😀 Five unique emoji characters
- 🔀 Two randomly shuffled arrays
- ⏱️ Decreasing display time
- 🎯 Position-based memory challenge
- ✅ Input validation
- 🏆 Score tracking
- 💀 Game-over system
- 🖥️ Command-line interface
- 🐍 Uses only Python standard libraries

---

🕹️ How to Play

1. 🎮 Start the game.
2. 👀 Observe the two emoji arrays.
3. 🧠 Memorize the positions of the emojis.
4. ⏳ Wait for the display time to finish.
5. 🖥️ The screen is cleared.
6. ⌨️ Enter the required emoji positions.
7. ✅ Correct answer → Continue to the next round.
8. ❌ Wrong answer → Game Over.
